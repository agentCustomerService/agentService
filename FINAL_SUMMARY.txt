================================================================================
API ENDPOINTS
================================================================================

POST /chat
  Purpose: Analyze user message, identify actions
  Input: message, order_id, (optional) session_id
  Output: pending_actions, executed_actions, awaiting_confirmation, logs
  
POST /actions/confirm
  Purpose: Execute or cancel pending actions
  Input: session_id, order_id, confirmed (true/false)
  Output: executed_actions, logs, response

GET /sessions
  Purpose: List all sessions
  
GET /sessions/{session_id}
  Purpose: Get session information
  
GET /sessions/{session_id}/history
  Purpose: Get interaction history

RAG Version Only:
  GET /policies
  GET /policies/list
  GET /policies/cancellation
  GET /policies/refund
  GET /policies/all

================================================================================
USAGE WORKFLOW
================================================================================

STEP 1: User sends message
$ curl -X POST http://localhost:8000/chat \
  -d '{"message": "cancel my order", "order_id": "ORD-12345"}'

Response shows:
  "pending_actions": ["cancel"]
  "awaiting_confirmation": true
  "logs": ["Pending actions to execute: cancel"]

STEP 2a: User confirms
$ curl -X POST http://localhost:8000/actions/confirm \
  -d '{
    "session_id": "550e8400...",
    "order_id": "ORD-12345",
    "confirmed": true
  }'

Result: Action executed

STEP 2b: Or user cancels
$ curl -X POST http://localhost:8000/actions/confirm \
  -d '{
    "session_id": "550e8400...",
    "order_id": "ORD-12345",
    "confirmed": false
  }'

Result: Action discarded
