## 🎯 Key Features

### ✓ Session Management
- Auto-generate UUIDs for new conversations
- Reuse sessions with session_id parameter
- Track creation and last-updated timestamps

### ✓ Persistent State
- Save full state snapshots after each execution
- SQLite database storage
- Retrievable for debugging/audit

### ✓ Conversation Memory
- Store all interactions per session
- Track: messages, order IDs, actions, logs, responses
- Retrieved and formatted for agent context

### ✓ Memory-Aware Agent
- LLM gets context of recent interactions
- Can reference past decisions
- Better informed actions in multi-turn conversations

### ✓ Query APIs
- List sessions: `GET /sessions`
- Session info: `GET /sessions/{id}`
- History: `GET /sessions/{id}/history`

## 🚀 Quick Start

### 1. Server Already Works
No configuration needed. Start it:
```bash
python app.py
```

### 2. First Request (Auto Session)
```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Cancel order 123",
    "order_id": "123"
  }'
```

Save the `session_id` from response.

### 3. Second Request (With Memory)
```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Refund the order",
    "order_id": "123",
    "session_id": "your-saved-session-id"
  }'
```

Agent now remembers order was cancelled.

### 4. View History
```bash
curl http://localhost:8000/sessions/your-session-id/history
```

### Smart Session Handling
```python
# First request - creates session
POST /chat {message, order_id}

# Second request - reuses session
POST /chat {message, order_id, session_id}
```

### Memory in Action
```
Interaction 1: "Cancel order ABC"
Interaction 2: "What's the status?"
→ Agent sees: "Order ABC was recently canceled"
→ Better context for response
```

### Database Design
```
sessions (metadata)
    ↓
state_history (full snapshots)
    ↓
interactions (readable history)
```

## 🔒 Design Principles

✅ **Stateless Agent** - Agent code unchanged, state managed externally
✅ **Separation of Concerns** - DB, State, Agent, API all modular
✅ **Simple & Scalable** - SQLite for simplicity, easy to migrate to PostgreSQL
✅ **Memory in Context** - No model retraining, just prompt injection
✅ **Optional Sessions** - Backwards compatible, auto-generates if not provided
