Welcome! This is the Agent Service with Action Confirmation System.

WHAT IS THIS?
═════════════════════════════════════════════════════════════════════════════
An AI-powered order management system that:
  ✓ Understands user requests (cancel, refund)
  ✓ Shows actions to user BEFORE execution
  ✓ Requires user confirmation
  ✓ Executes only what user approves
  ✓ Maintains complete audit trail

QUICK START (5 minutes)
═════════════════════════════════════════════════════════════════════════════

Step 1: Install
  $ pip install -r requirements.txt

Step 2: Start
  $ uvicorn app:api --reload

Step 3: Test
  $ curl -X POST http://localhost:8000/chat \
    -H "Content-Type: application/json" \
    -d '{"message":"cancel my order","order_id":"123"}'

Step 4: Confirm
  $ curl -X POST http://localhost:8000/actions/confirm \
    -H "Content-Type: application/json" \
    -d '{"session_id":"...","order_id":"123","confirmed":true}'

That's it! You can now process orders safely.

API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

POST /chat
  Send a message and get pending actions
  Response shows actions awaiting confirmation

POST /actions/confirm
  Confirm (confirmed=true) or cancel (confirmed=false) actions

GET /sessions
  List all sessions

GET /sessions/{id}
  Get session details

GET /sessions/{id}/history
  Get interaction history

TYPICAL WORKFLOW
═════════════════════════════════════════════════════════════════════════════

1. User says: "I want to cancel my order"
   System identifies: action="cancel"
   Shows: pending_actions: ["cancel"]
   Status: awaiting_confirmation=true

2. User reviews and confirms
   POST /actions/confirm with confirmed=true

3. System executes: Order cancelled
   Returns: executed_actions: ["cancel"]
   Status: Response shows completion

═════════════════════════════════════════════════════════════════════════════

CONFIGURATION
═════════════════════════════════════════════════════════════════════════════

LLM:
  Tries local Ollama first (no key needed)
  Falls back to Google Genai (set GOOGLE_API_KEY)

Database:
  SQLite (agent_state.db)
  Auto-created on first run
  Sessions and history preserved

Server:
  Development: uvicorn app:api --reload
  Production: uvicorn app:api --host 0.0.0.0 --port 8000

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Problem: ImportError langchain_ollama
Solution: pip install langchain-ollama

Problem: GOOGLE_API_KEY required
Solution: export GOOGLE_API_KEY=your-key

Problem: Session not found
Solution: Use exact session_id from /chat response

Problem: No actions identified
Solution: Use clearer message like "cancel my order"
